# Bubble Bobble (버블보블) — HTML5 팬 리메이크

1986년 아케이드 고전 **버블보블**을 브라우저에서 즐길 수 있도록 순수 HTML5 Canvas + JavaScript로 만든 게임입니다.
외부 라이브러리나 이미지·사운드 파일 없이 동작하며, 태블릿 터치 조작에 맞춰 만들어졌습니다.

## 실행 방법

* **GitHub Pages**: 저장소 *Settings → Pages* 에서 브랜치를 선택해 배포하면
  `https://<사용자명>.github.io/Bubblegame/` 주소로 바로 플레이할 수 있습니다.
* **로컬**: `index.html`을 브라우저로 열거나, 아무 정적 서버로 폴더를 서비스하면 됩니다.
* **태블릿 홈 화면 추가**: Safari/Chrome 에서 "홈 화면에 추가"를 하면 전체 화면 앱처럼 실행됩니다.
  우측 상단 ⛶ 버튼으로 전체 화면(가로 고정)도 가능합니다.

## 조작

| 동작 | 태블릿 | 키보드 |
|------|--------|--------|
| 이동 | 왼쪽 하단 ◀ ▶ 패드 | ← → (또는 A / D) |
| 점프 | JUMP 버튼 | Z, Space, ↑ |
| 버블 | BUBBLE 버튼 | X, Shift, Ctrl |
| 시작 / 컨티뉴 | 화면 터치 | Enter |
| 일시정지 | – | P / Esc |
| 음소거 | 🔊 버튼 | M |

## 구현된 원작 요소

* 256×224 아케이드 해상도를 화면 크기에 맞춰 **정수 배율·픽셀 퍼펙트**로 확대 (Retina 대응, 흐림 없음)
* 100 라운드, 라운드 100 보스전(슈퍼 드렁크)과 엔딩
* 8종의 몬스터: 젠짱, 마이타(바위), 몬스타, 풀풀, 바네보우, 히데곤스(불꽃), 드렁크(병), 인베이더(레이저)
* 버블 물리: 발사 → 상승 → 바람 방향으로 모임, 버블 타기·버블 점프, 연쇄 터뜨리기
* 몬스터 포획 → 시간 초과 시 탈출(분노 상태), 터뜨리면 과일로 변환, 연쇄 점수 1000 → 2000 → 4000 … 64000
* 특수 버블: 물(급류), 불(바닥 화염), 번개, **EXTEND** 글자 모으면 1UP
* 아이템: 캔디 3종(연사·속도·사거리), 신발, 우산(라운드 스킵), 십자가 3종(화염·홍수·번개), 포션(보너스)
* HURRY UP!! 경고 후 무적 해골 몬스터(바론 폰 블루바) 등장
* 바닥 구멍으로 떨어지면 천장으로 순환
* 라운드 전환 스크롤, 오프닝 스토리 텍스트, 게임 오버 컨티뉴, 최고 점수 저장(localStorage)
* WebAudio 로 합성한 칩튠 BGM 과 효과음 (서두르기 상태에서 템포 상승)

## 파일 구성

```
index.html      진입점 / 터치 컨트롤 마크업
css/style.css   레이아웃 및 터치 버튼
js/sprites.js   모든 도트 그래픽(텍스트로 정의) 과 8x8 폰트
js/audio.js     칩튠 시퀀서 및 효과음
js/input.js     키보드 · 멀티터치 입력
js/levels.js    100 라운드 레이아웃, 팔레트, 몬스터 배치
js/engine.js    게임 엔진(물리, AI, 버블, 아이템, 상태, 렌더링)
manifest.json   PWA 매니페스트 / 아이콘
```
